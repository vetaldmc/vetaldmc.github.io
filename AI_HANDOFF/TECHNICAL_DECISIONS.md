# TECHNICAL DECISIONS

## TD-001: Единый style.css для EN и UK
- **Решение**: один CSS-файл в корне, UK-страницы ссылаются на `../style.css`.
- **Причина**: избежать дублирования, единая тема.
- **Последствия**: изменение стиля отражается на обеих версиях синхронно.
- **Ограничения**: при рассинхронизации контента CSS остаётся общим.
- **Пересмотр**: если появится третья версия (например, RU) — рассмотреть CSS-модули или сборку.
- **Статус**: FACT (по коду).

## TD-002: CSS custom properties для темы
- **Решение**: переменные в `:root`, переопределение через `@media (prefers-color-scheme: light)`.
- **Причина**: автоматическая тема, минимум JS.
- **Последствия**: нет ручного toggle — см. TODO P0.
- **Ограничения**: `prefers-color-scheme` работает не во всех встраиваемых браузерах.
- **Пересмотр**: добавить `[data-theme]` для ручного управления.
- **Статус**: FACT.

## TD-003: CheerpJ для Java в браузере
- **Решение**: CheerpJ 3.0 через CDN `cjrtnc.leaningtech.com/3.0/loader.js`.
- **Причина**: возможность запустить Java Swing/AWT без переписывания на JS.
- **Последствия**: ~10–20 MB загрузки, внешняя зависимость.
- **Ограничения**: JavaFX и тяжёлый 3D (LWJGL) не поддерживаются (FACT — из README.txt).
- **Пересмотр**: **рекомендуется lazy-load** — загружать CheerpJ только по клику на «Play».
- **Статус**: FACT.

## TD-004: Google Fonts (Manrope)
- **Решение**: подключение через `<link>` с `display=swap` и `subset=cyrillic`.
- **Причина**: быстрый старт, кириллица для UK.
- **Последствия**: внешний запрос, potential FOUT.
- **Ограничения**: privacy (GDPR для EU), задержка при холодном кэше.
- **Пересмотр**: рассмотреть self-host `.woff2` (P2).
- **Статус**: FACT.

## TD-005: Дублирование HTML EN/UK
- **Решение**: две папки/набора файлов вместо i18n-слоя.
- **Причина**: простота статического хостинга без сборки.
- **Последствия**: ручная синхронизация, риск рассинхронизации.
- **Ограничения**: масштабирование на 3+ языков болезненно.
- **Пересмотр**: если языков >2 — рассмотреть SSG (Astro/Eleventy).
- **Статус**: FACT.

## TD-006: Inline `<script>` для CheerpJ
- **Решение**: скрипт прямо в game.html.
- **Причина**: минимум файлов, простая логика.
- **Последствия**: нарушает strict CSP (если появится), дублируется EN/UK.
- **Пересмотр**: вынести в `game.js` при рефакторинге.
- **Статус**: FACT.

## TD-007: iframe для resume-doc.html
- **Решение**: `<iframe class="paper" src="resume-doc.html">`.
- **Причина**: быстрый предпросмотр печатной версии.
- **Последствия**: LCP-проблема на resume.html (iframe грузится сразу).
- **Пересмотр**: добавить `loading="lazy"` (P0), либо показывать превью-изображение с кнопкой.
- **Статус**: FACT.
