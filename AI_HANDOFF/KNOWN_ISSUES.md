# KNOWN ISSUES

## Подтверждённые ошибки (FACT)

### ISSUE-001: game.html не запускает игру
- **Местоположение**: `game.html` (EN и UK), строка `cheerpjRunJar("/app/game/game.jar")`.
- **Причина**: файл `game/game.jar` отсутствует в проекте.
- **Последствия**: страница показывает ошибку или вечное «Загрузка…».
- **Приоритет**: P0 (если игра — ключевая функция) / P1 (если второстепенная).
- **Статус**: открыта.

### ISSUE-002: Абсолютный путь к jar
- **Местоположение**: `game.html`, `cheerpjRunJar("/app/game/game.jar")`.
- **Причина**: `/app/...` — абсолютный путь от корня домена.
- **Последствия**: при деплое в подкаталог (GitHub Pages project page, `/repo-name/`) — 404.
- **Приоритет**: P1.
- **Статус**: открыта. Исправление: относительный путь `game/game.jar` или `../game/game.jar`.

### ISSUE-003: Блокирующая загрузка CheerpJ
- **Местоположение**: `game.html`.
- **Причина**: `<script src="...loader.js">` + `cheerpjInit()` при `DOMContentLoaded`.
- **Последствия**: LCP страницы измеряется десятками секунд на мобильных.
- **Приоритет**: P1.
- **Статус**: открыта. Исправление: lazy-load по клику.

### ISSUE-004: Placeholder-контент на projects.html
- **Местоположение**: `projects.html` (EN и UK), карточки `<h3>Project name</h3>`.
- **Причина**: контент не заполнен.
- **Последствия**: выглядит незавершённым для посетителей.
- **Приоритет**: P1 (репутационный).
- **Статус**: открыта.

### ISSUE-005: Битые символы в UK PDF (при извлечении)
- **Местоположение**: `resume.pdf` (UK).
- **Причина**: UNKNOWN (возможно, артефакт извлечения текста, а не сам PDF; возможно, проблема с кодировкой шрифта в PDF).
- **Последствия**: если PDF реально содержит битые символы — плохо для ATS.
- **Приоритет**: P1 (если подтвердится).
- **Статус**: UNKNOWN — требует визуальной проверки PDF.

### ISSUE-006: Нет мобильного меню
- **Местоположение**: `<nav>` во всех HTML.
- **Причина**: только `flex-wrap`.
- **Последствия**: на узких экранах меню переносится в 2–3 строки, занимает много места.
- **Приоритет**: P0.
- **Статус**: открыта.

### ISSUE-007: Нет ручного переключателя темы
- **Местоположение**: все страницы.
- **Причина**: только `prefers-color-scheme`.
- **Последствия**: пользователь не может выбрать тему вручную.
- **Приоритет**: P0.
- **Статус**: открыта.

## Потенциальные риски (ASSUMPTION)

### RISK-001: Рассинхронизация EN/UK
- **Причина**: дублирование HTML.
- **Последствия**: разные версии контента, битые кросс-ссылки.
- **Приоритет**: P2.

### RISK-002: Google Fonts и GDPR
- **Причина**: внешний запрос к fonts.googleapis.com.
- **Последствия**: потенциальные претензии для EU-аудитории.
- **Приоритет**: P3.

### RISK-003: iframe resume-doc.html — LCP
- **Причина**: загрузка iframe сразу.
- **Последствия**: медленный LCP на resume.html.
- **Приоритет**: P1.

### RISK-004: Нет CSP
- **Причина**: inline JS, внешние CDN.
- **Последствия**: уязвимость при XSS (маловероятно для статики, но best practice).
- **Приоритет**: P3.
