My road: engineer to developer

I think like an engineer: break a system into parts, find the fault, fix it, document it. I chose code because it lets me build the same way without needing a roof or a power grid.

Where I have been

2014 – 2018

Automation engineering, college

  • Installation and maintenance of automation systems. Repaired phones, tablets and appliances on the side, soldering at board level.
2018 – 2019

Shift electrician, mining and processing plant

  • Motors, lighting, automation circuits. Designed and introduced new automation schemes.
2020 – 2021

Solar installer and commissioning technician

  • Roof calculations, panels, inverters, switchgear, configuration.
2021 – 2023

Foreman

  • Led crews across Ukraine, handled procurement, budgets, payroll, proposals and client talks.
2023 – 2024

Head of the installation department

  • Planned and ran installations, trained crews, worked with suppliers, cut costs by 40% without losing quality.
2024 – 2026

Remote support and VIP account management

  • Moved online when field work became impossible. Technical support engineer, then customer support and VIP manager in iGaming, working with CRM, Jira, Confluence and analytics tools.

Where I am going

Phase 1: Java foundation

Core Java, OOP, collections, exceptions, streams. Small console programs on GitHub.

Phase 2: Tools

Git and GitHub, Maven, SQL with PostgreSQL, JUnit tests, Linux basics.

Phase 3: Backend

Spring Boot, REST APIs, JPA/Hibernate, authentication, Docker.

Phase 4: Portfolio project

A real backend for a domain I know, for example monitoring of solar systems, with tests and documentation.

Phase 5: First IT role

Application or Technical Support to start inside a product team, then Junior Java Developer.

The path was not easy, and every obstacle taught me something I now use: staying calm on a broken system, working with people under pressure, finishing what I start.
